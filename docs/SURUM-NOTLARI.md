Windows 10 ve Windows 11 için PDF Viewer.

- Tek EXE ile kullanıcı hesabına kurulum; ayrıca .NET yüklemek gerekmez.
- Yerel PDF görüntüleme, sayfa gezinmesi, yakınlaştırma ve tema seçenekleri.
- Uygulamadaki **Güncelle** düğmesiyle yeni sürüm denetleme ve onaylı kurulum.

Çoğu Windows bilgisayarı için **PDF-Viewer-Setup-x64.exe** dosyasını indirin. ARM işlemcili bilgisayarlar için **PDF-Viewer-Setup-arm64.exe** dosyasını kullanın.

Bu ilk sürümdür. Kurulum dosyası henüz kod imzalama sertifikasıyla imzalanmamıştır; Windows tanınmayan yayımcı uyarısı gösterebilir. Windows 10/11 üzerinde kapsamlı belge ve cihaz testleri sürmektedir.
